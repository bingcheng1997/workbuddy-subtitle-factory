# 双语字幕工厂

WorkBuddy 技能：把音频或视频变成可直接导入剪映的双语字幕文件。

一个文件进，一套字幕出——SRT（双语两行，剪映直导）、VTT、ASS 双语字幕条，外加一份质检报告。转写、断句、翻译、排版全自动，术语译名全程一致。

## 功能

- **灵活获取文字稿**：支持模型直接转写；已有文字稿或剪映导出的 SRT 可直接接手；已配置云转写连接器时也可调用（使用前先征得同意）
- **专业断句规范**：中文每行 ≤ 20 字、英文每行 ≤ 42 字符；阅读速度中文 ≤ 9 字/秒、英文 CPS ≤ 17；时间轴不重叠、间隔 ≥ 80ms
- **术语译名一致**：提供术语表（文件或对话里随手列出）后强制统一译名；数字、品牌名、专有名词不译；中英混说内容不重复翻译
- **三种输出格式**：SRT 双语两行（剪映 → 文本 → 导入字幕）、VTT（网页播放器）、ASS 双语字幕条（译文白色主字号在下、原文灰色小字号在上）
- **章节标记**：按内容自然段切 9~12 个章节（`00:00 章节名`），B 站 / YouTube 投稿简介直接粘贴
- **质检报告**：摘要（条数、时长、没听清片段、术语落实）+ 超长/超速明细，交付前自动复检时间轴

## 安装

1. 下载 [Releases](../../releases) 中的技能包 zip
2. 打开 WorkBuddy → 技能栏 → 导入本地技能包 → 选择 zip
3. 也可以把仓库中的 `SKILL.md` 放入 `~/.workbuddy/skills/bilingual-subtitle-factory/`

## 使用

对 WorkBuddy 说：

```
帮我把这个视频做成中英双语字幕
把这个会议录音转成字幕，WorkBuddy 这个词别翻错
字幕里这几个术语按我的表来：影子跟读 shadowing、连读 liaison
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| 源文件 | 必填 | 音频 / 视频 / 文字稿 / SRT，支持本地文件路径 |
| 目标语言 | 源为中文时译英文 | 可指定任意方向 |
| 输出格式 | SRT | 可多选 SRT / VTT / ASS |
| 术语表 | 无 | 文件（每行 `原文,译文`）或对话直接列出 |

只需提供源文件，其余参数自动取默认值，交付时一并告知所用配置。

## 输出物

保存到 `字幕输出/`：

```
course01.zh-en.srt        双语字幕（剪映 / PR / 达芬奇直导）
course01.zh-en.vtt        网页播放器用
course01.zh-en.ass        双语字幕条样式
章节标记.txt               B 站 / YouTube 投稿用
course01_质检报告.md       摘要与明细
```

## 使用须知

- 仅处理你拥有权利的音视频；网课、影视等非本人录制内容请先确认授权
- 音频直转能力取决于模型对音频输入的支持；推荐路径是「剪映智能字幕出中文稿 → 本技能接手翻译排版」，全程无需配置云 API
- 时间轴精度取决于转写引擎，建议抽查开头 / 中间 / 结尾各 1 分钟
- 法律、医疗、金融内容请人工复核译文

## 测试

仓库内置自动化测试（断句规范、时间轴约束、术语一致性、输出格式回读）：

```bash
cd tests && python3 run_tests.py
```
